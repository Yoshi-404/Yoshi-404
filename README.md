### About me

- **Computer Engineering** undergraduate at **UFGD** (Brazil).
- Academic exchange in Systems Engineering at **Wakayama University (和歌山大学)**, Japan.
- International proficiency certifications: **JLPT N1** (Japanese, obtained in 2020) and **TOEIC 840 points** (English, advanced level).
- Building **UniFluxo** (Flutter) as my undergraduate thesis project, focused on centralizing university routines.
- Developed **The Shining Maze**, a 3D maze rendered with OpenGL, featuring projection math and a CI/CD pipeline via GitHub Actions.
- Hands-on focus on visual computing, interface design systems and streetwear culture (with an interest in classic brands like Onitsuka Tiger).
